# swansong-adopt-dryrun

Scratch repository. It exists to rehearse a project adopting Swansong's
maintainer-signed review gate before Waybill does: `swansong repo adopt`,
an approver signing off with `swansong pr approve`, the `review-gate` status
on a pull request's head, and `swansong pr merge`.

Nothing here is real software. Expect it to be reset or deleted.
